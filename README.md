# zqshi

> 做 AI 原生的交付与运行时基础设施：让 Agent 做完的事不蒸发，踩过的坑不重来。

坐标北京。关注 Agent 工程、人机协同、任务交付闭环，以及 Agent 大规模进入企业后的质量治理与可信交易问题。

## 关注方向

- **交付闭环** —— 任务、执行、验收、成本、评测形成可追溯的证据链，而不是一次性输出
- **人机协同** —— 人在决策回路中的位置、权限与责任边界
- **经验沉淀** —— 让 Agent 的每次迭代变成可复用的组织知识
- **可信交易** —— Agent 参与生产后，成果如何被定价、验证与结算
